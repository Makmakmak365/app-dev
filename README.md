# My Favorite Series: Breaking Bad

**Breaking Bad** is an American crime drama television series created by Vince Gilligan. 

## Why I Love It
- **Incredible Character Development:** Watching Walter White transform over five seasons is unforgettable.
- **Suspenseful Writing:** Every episode builds tension masterfully.
- **Cinematography:** The visual storytelling and use of color are iconic.

## Main Characters
1. Walter White
2. Jesse Pinkman
3. Saul Goodman
4. Hank Schrader

> "I am not in danger, Skyler. I am the danger." — *Walter White*
